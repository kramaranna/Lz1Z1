1. Аналіз коду
Призначення класів:

- Graphics — клас, який надає методи для малювання та виведення графічних примітивів (ліній, прямокутників, багатокутників тощо) на поверхню елемента управління або форми.

- Pen — клас, призначений для створення пера, яке визначає колір, стиль і товщину ліній та контурів фігур.

- Brush — базовий абстрактний клас для створення кисті, яка використовується для заповнення (зафарбовування) внутрішньої області замкнених фігур.

Що виконує команда graf->Clear(Color::White);?

- Повністю очищує графічну поверхню (полотно), заливаючи її білим кольором. Використовується для видалення попередньо намальованих фігур перед виведенням нових.

Що означає listBox1->SelectedIndex?

- Це властивість, яка повертає числовий індекс (порядковий номер) вибраного в даний момент рядка у списку ListBox (індексація починається з 0). Якщо нічого не вибрано, повертає значення -1.
  
2. Встановлення відповідності 

- Індекс 0: Лінія
- Індекс 1: Прямокутник
- Індекс 2: Зафарбований прямокутник
- Індекс 3: Еліпс
- Індекс 4: Зафарбований еліпс
- Індекс 5: Сектор
- Індекс 6: Зірка
- Індекс 7: Трикутник 
- Індекс 8: Будиночок

## 📝 Висновки
Під час виконання лабораторної роботи було освоєно графічні можливості середовища MS Visual Studio C++ (Windows Forms). Зокрема, навчилися використовувати класи Graphics, Pen та Brush для побудови геометричних фігур і роботи з растровою поверхнею форми. Опанували механізм обробки подій вибору елементів зі списків (ListBox та ComboBox), що дозволило реалізувати динамічну зміну параметрів відображення, кольору та товщини об'єктів. Закріплено навички використання умовного оператора switch для керування вибором фігур та обробки масивів координат для складніших багатокутників.
